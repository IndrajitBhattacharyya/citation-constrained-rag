# Citation-Constrained Prompting in a Local Medical RAG Pipeline — Source Code

Companion code for the seminar paper 

This package aims to reproduce the numbers and figure in the paper. It runs a fully
**local** medical RAG pipeline — 18 MedQA textbooks indexed with FAISS, retrieval
with a sentence-transformer, and `qwen2.5:3b` served by Ollama — on an 8 GB laptop.
